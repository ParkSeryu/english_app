# WCT 퀴즈 정답 확인 버튼 디자인

## 목적

보기를 누르는 즉시 정답이 공개되는 현재 흐름을, 사용자가 답을 선택한 뒤 `정답 확인` 버튼으로 명시적으로 확정하는 흐름으로 바꾼다.

## 상호작용

- `정답 확인` 버튼은 보기 아래에 항상 표시한다.
- 보기를 선택하기 전에는 버튼을 비활성화한다.
- 보기를 선택하면 버튼을 활성화하고, 확인 전에는 다른 보기로 선택을 바꿀 수 있다.
- `정답 확인`을 누를 때 현재 선택을 답안 배열에 한 번만 기록한다.
- 확인 후에는 모든 보기를 잠그고 정답·오답 스타일, 피드백, 해설을 공개한다.
- 확인 후 버튼은 기존처럼 `다음 문제`로 바뀌며, 마지막 문제에서는 `결과 보기`로 바뀐다.
- 다음 문제와 다시 풀기에서는 선택 및 확인 상태를 초기화한다.

## 변경하지 않는 범위

- 문제 구성과 순서
- 정답 판정 기준과 서버 측 점수 계산
- 결과 저장, 저장 재시도, 다시 풀기 동작
- 표준 WCT와 Premium WCT의 퀴즈 라우트
- Day 상세의 퀴즈 진입 버튼

## 오류 처리

- 선택하지 않은 상태에서는 `정답 확인`을 실행할 수 없다.
- 이미 확인한 답은 다시 기록하지 않는다.
- 결과 저장 오류 처리는 현재 동작을 그대로 유지한다.

## 테스트

- 선택 전 `정답 확인` 버튼이 비활성인지 확인한다.
- 선택만 했을 때 정답·오답 및 해설이 공개되지 않는지 확인한다.
- 확인 전 다른 보기로 선택을 변경할 수 있는지 확인한다.
- `정답 확인` 후 선택이 잠기고 피드백·해설이 공개되는지 확인한다.
- 다섯 문제에서 확인된 답만 한 번씩 저장되는지 확인한다.
- 표준 및 Premium WCT E2E에서 매 문제 `정답 확인`을 거쳐 다음 문제와 결과로 이동하는지 확인한다.

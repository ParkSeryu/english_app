# WCT 퀴즈 CTA 버튼 디자인

## 목적

WCT Day 상세의 퀴즈 진입 요소를 작은 배지에서 모바일에서도 즉시 알아볼 수 있는 전체 너비 버튼으로 바꾼다.

## 디자인

- 기존 `WctQuizBadge`가 있는 위치를 유지한다.
- 링크를 전체 너비의 진한 청록색 둥근 사각형 버튼으로 표현한다.
- 충분한 세로 여백과 명확한 hover·focus 상태를 제공한다.
- 미완료 상태는 왼쪽에 `문제 풀기`, 오른쪽에 `5문제`처럼 문항 수를 표시한다.
- 완료 상태는 왼쪽에 `다시 풀기`, 오른쪽에 `최근 4/5`처럼 최근 점수를 표시한다.
- 일반 WCT Day와 Premium Day에 동일한 컴포넌트를 사용한다.

## 변경하지 않는 범위

- 퀴즈 링크와 페이지 이동 방식
- 문제 생성, 채점, 결과 저장, 재도전 동작
- Day 상세에서 버튼이 놓이는 순서
- 퀴즈가 없는 Day에서 아무것도 표시하지 않는 동작

## 테스트

- 미완료 상태가 `문제 풀기`와 문항 수를 표시하는지 확인한다.
- 완료 상태가 `다시 풀기`와 최근 점수를 표시하는지 확인한다.
- 링크 목적지가 기존과 동일한지 확인한다.
- 전체 너비의 주요 버튼 스타일과 키보드 focus 스타일이 적용되는지 확인한다.
- 일반 WCT Day와 Premium Day 상세에서 실제 버튼 배치와 이동을 확인한다.

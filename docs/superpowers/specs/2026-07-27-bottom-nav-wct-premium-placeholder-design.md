# 하단 GNB 재배치 및 WCT Premium 항목 설계

## 목표

- 하단 GNB를 왼쪽부터 `표현 · 암기 · 수업 · 묘사 · 질문` 순서로 구성한다.
- `수업` 화면에 내용이나 상세 페이지가 없는 `WCT Premium` 준비 중 항목을 표시한다.

## UI 동작

### 하단 GNB

- 기존 링크와 활성 상태 판정은 유지한다.
- 항목 순서만 `표현`, `암기`, `수업`, `묘사`, `질문`으로 바꾼다.
- 기존 `질문거리` 라벨은 `질문`으로 줄인다.
- 각 항목의 경로는 기존 값을 유지한다.

### WCT Premium

- `/lessons`의 기존 WCT 교재 목록 영역에 `WCT Premium` 카드를 항상 표시한다.
- 카드에는 `WCT Premium`과 `준비 중`만 표시한다.
- 카드는 링크나 버튼이 아니며 클릭 동작이 없다.
- 기존 교재 카드, 교재 조회, 빈 상태 안내는 그대로 유지한다.

## 구현 범위

- `BottomNav`의 항목 배열을 재배치하고 질문 라벨을 변경한다.
- 기존 교재 카드와 구분되는 정적 Premium 준비 중 카드를 추가한다.
- 데이터 저장소, 타입, API, 라우트, 데이터베이스 스키마는 변경하지 않는다.

## 검증

- 컴포넌트 테스트에서 GNB 링크의 순서와 라벨을 확인한다.
- Premium 카드의 문구가 보이고 링크나 버튼이 아님을 확인한다.
- lint, typecheck, 관련 컴포넌트 테스트를 실행한다.
- 실행 중인 앱에서 `/lessons`와 하단 GNB를 확인한다.

## 비목표

- WCT Premium 상세 페이지나 학습 콘텐츠를 만들지 않는다.
- Premium 교재 데이터를 DB에 추가하지 않는다.
- 기존 WCT 교재 카드의 동작이나 디자인을 변경하지 않는다.
